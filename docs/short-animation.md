# 短动画通用流程

适用于冷开场、转场、片头片尾等十几秒的创意短动画。第一个完整案例：`projects/2026-09-16-magic-pictorial/coldopen/make_coldopen.py`。

## 工具：一个 Python 脚本

- PIL 逐帧绘制画面，numpy 做质感（录像带、故障、噪点）和合成声音，ffmpeg 通过管道接收原始帧并编码为 H.264 + AAC。
- 不引入渲染框架：逐像素质感最好控制，结果可复现，没有新增依赖，任何一帧都能单独截出来检查。
- 脚本放在项目目录下（如 `projects/<项目>/coldopen/`），成片放 `assets/generated/<项目>-<名称>/`，临时文件放 `tmp/`，用完清理。
- 脚本开头用注释写清时间线：每个节点的秒数和发生了什么，常量与注释一一对应。需要对比多种质感时，用命令行参数切换（如 `vhs` / `clean`），时间线和内容共用。

## 工作循环

1. **先规划，再动手。** 每轮改动前先说明要改什么、为什么、代价是什么；涉及构思、风格或结构的改动，等用户确认。
2. **在好的版本上小改。** 用户认可的版本是基线，每轮只改用户指出的问题。改多了容易把做对的东西也改丢；改坏了就退回基线，不在坏版本上继续叠加。
3. **渲染后自查。**
   - 在关键时间点截图，拼成一张联系表，逐帧看。
   - 小字、眼睛、按钮这类细节，截局部放大看。
   - 镜头运动逐帧算速度，确认没有掉到零的卡顿。
   - 用 ffprobe 检查时长、尺寸、帧率、编码、音轨。
4. **交付时说清楚**：改了什么、怎么验证的、还有哪些没做（字体许可、正式素材等）。只保留选定版本，其余成片删掉。

## 技术坑

- **中文字形**：Consolas 等等宽字体没有中文，会显示成方框。凡是含中文的文字，都用中文字体。
- **镜头连续**：几段慢起慢停的曲线拼在一起，接缝处速度会归零，看起来像卡顿。用一条一直在走的底速曲线，需要冲击时再叠加一段临界阻尼的推进，冲上去以后平滑收住。
- **有状态的元素**（视线跟随、延迟、回声）只能在顺序渲染中测试；单独抽几帧测，结果会失真。
- **性能**：静态图层（壁纸、背景光、复用的图标页）缓存起来；每帧都要变的才每帧画。
- **预览与正式版**：预览可以用系统字体和合成声音；正式版换成可商用字体和有许可证的素材，记入 `manifest.yaml`。
