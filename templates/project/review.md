# 发布前检查

## 内容

- [ ] 核心事实已核实并可追溯
- [ ] 标题与正文没有夸大或偷换概念
- [ ] 人名、数字、日期、专有名词正确

## 权利与合规

- [ ] 素材、音乐、字体、肖像和声音均有授权记录
- [ ] 每个外部内容资产都有 asset ID、来源和权利状态
- [ ] 画面标记已评估；任何修改都有独立授权与处理记录
- [ ] AI 生成内容已按平台要求标识
- [ ] 不含密钥、私人信息或未公开资料

## 视频

- [ ] 分辨率、帧率、时长和画幅正确
- [ ] 字幕无错字、遮挡或超出安全区
- [ ] 无黑帧、静帧、音画错位、爆音或削波
- [ ] 首帧、前三秒、结尾和 CTA 已人工观看

## 发布包

- [ ] 最终 MP4
- [ ] SRT 字幕
- [ ] 封面
- [ ] 标题、简介、标签和来源说明
